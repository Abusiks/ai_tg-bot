# 🤖 Local Qwen Telegram Bot (Ollama + Python)

Локальный Telegram‑бот на базе **Qwen 2.5 Coder** через **Ollama** — полностью работает локально, без облачных API. Идеальное решение для приватного AI‑ассистента с фокусом на программирование.

## ✨ Ключевые возможности

- 💬 Чат с локальной LLM (Qwen 2.5 Coder 14B/7B)
- 🧠 Контекст диалога (память между сообщениями)
- ⌨️ Индикатор «печатает…» (`typing…`)
- ⚡ Быстрые ответы через Ollama API
- 🧹 Очистка истории диалога командой `/clear`
- 🔄 Автоматическое обрезание длинных ответов
- 👥 Работа в группах (с настройкой Group Privacy)
- 📦 Полностью локальный стек — данные не покидают ваш компьютер
- 🛠️ Оптимизирован для задач программирования (код, отладка, объяснения)

## 🧱 Архитектура системы

Telegram → Python Bot → Ollama API → Qwen Model
## 🖥️ Системные требования
Минимальные:

Python 3.10+

ОЗУ: 8 ГБ (для модели 7B)

Место на диске: 10 ГБ

Рекомендуемые:

ОЗУ: 16+ ГБ (для модели 14B)

Место на диске: 20 ГБ

Установленный Ollama

# 📦 Установка Ollama
## 🍎 macOS

brew install ollama

ollama serve
## 🐧 Linux
curl -fsSL https://ollama.com/install.sh | sh

ollama serve

## 🪟 Windows
Скачайте установщик с официального сайта ollama.

Запустите установщик.

После установки выполните в командной строке:


ollama serve

## 📥 Загрузка модели Qwen 2.5 Coder
Рекомендуемая (для качественных ответов):


ollama pull qwen2.5-coder:14b

Облегчённая (для слабых ПК):


ollama pull qwen2.5-coder:7b


ollama run qwen2.5-coder:14b # запуск

Введите любой текст (например, Hello) и убедитесь, что модель отвечает.

## 🔌 Проверка Ollama API
Убедитесь, что сервер Ollama работает корректно:

curl http://localhost:11434/api/generate -d '{
  "model": "qwen2.5-coder:14b",
  "prompt": "Hello",
  "stream": false
}'

Если приходит ответ — сервер работает корректно.

# 📁 Установка проекта
Клонируйте репозиторий:

git clone <https://github.com/Abusiks/ai_tg-bot.git>

cd telegram-qwen-bot

## Создайте и активируйте виртуальное окружение:

Linux/macOS:

python3 -m venv venv

source venv/bin/activate

Windows:

python -m venv venv

venv\Scripts\activate

Установите зависимости:

pip install -r requirements.txt

🔐 Настройка конфигурации

Создайте файл .env в корне проекта со следующим содержимым:

## .env

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

OLLAMA_URL=http://localhost:11434

MODEL=qwen2.5-coder:14b  # или qwen2.5-coder:7b для слабой системы

# Получение токена Telegram‑бота:

Откройте Telegram и найдите @BotFather.

Отправьте команду /newbot и следуйте инструкциям.

Получите токен и вставьте его в .env вместо YOUR_TELEGRAM_BOT_TOKEN.

🔐 Настройка видимости в группах (Group Privacy)
По умолчанию бот видит только сообщения, в которых его упомянули, и команды, начинающиеся с /.

Чтобы бот видел все сообщения в группе:

Напишите @BotFather и выберите /mybots.

Выберите своего бота.

Перейдите в Bot Settings → Group Privacy и нажмите Turn off.

⚠️ Важно: после изменения настройки необходимо удалить бота из группы и добавить заново, чтобы изменения вступили в силу.

# 🚀 Запуск бота
Базовый запуск:

python app.py

Запуск через Uvicorn (для вебхуков):

uvicorn app:app --host 0.0.0.0 --port 8000

💬 Доступные команды

Команда	Описание

/start	Приветствие и справка по использованию

/clear	Очистить историю диалога (сбросить контекст)

Особенности работы в группах:

Privacy Mode включён: бот реагирует только на команды (начинающиеся с /) и упоминания.

Privacy Mode выключен: бот отвечает на любое сообщение в группе.

## ⚡ Примечания и рекомендации
Для слабых устройств используйте модель qwen2.5-coder:7b.

Для максимального качества ответов — qwen2.5-coder:14b.

Сервер Ollama должен быть запущен (ollama serve) перед стартом бота.

Убедитесь, что порт 11434 доступен и не занят другими сервисами.

При медленных ответах проверьте использование памяти (возможно, система использует swap).

Для экономии ресурсов можно ограничить количество загруженных моделей через переменную окружения OLLAMA_MAX_LOADED_MODELS=1.
